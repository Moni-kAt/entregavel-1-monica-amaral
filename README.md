# Entregável 1 - Aprendendo a ser um programador

## Nome
Mônica Amaral

## Objetivo

Este programa verifica se um robô possui bateria suficiente para concluir uma missão.

Para isso, são informados:
- bateria atual;
- duração da missão;
- consumo de bateria por minuto.

O programa calcula o consumo total e informa se a missão pode ser concluída.

## Requisitos

- Python 3

## Como executar

Na pasta principal do projeto, execute:

```bash
python3 src/missao.py
